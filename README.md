A kernel and a UEFI bootloader written from scratch in Rust.

# Info
This does not requires any linker script trickery. Both the kernel and the
bootloader are generated by the Rust compiler as individual statically linked
binaries.

The kernel is a freestanding ELF executable of some target
architecture(currently x86 only) and the bootloader is a PE32+ executable of
the appropriate architecture. Both are statically compiled and have no external
3rd party dependencies.

The kernel requires some externally assembled x86 assembly code like the files
`irq.asm` and `isr.asm` which are build using NASM which then get linked by the
Rust compiler.

Some helper shell scripts are provided which put the kernel and the bootloader
in appropriate disk images for use with QEMU, which has its own helper scripts.

There are helper `just` commands to do various tasks.

## Requirements
- Rust nightly toolchain
- NASM assembler
- Just, the command runner
- QEMU, specifically qemu-system-i386

## `Just` commands for running.
- `just full` to rebuild the kernel plus bootloader and run them.
- `just build` to build both the kernel and the bootloader.
- `just run` to only run the kernel plus bootloader, without building then again.
   Before using this, use `just build` at least once.
- `just kernel` to build the kernel only.
- `just uefi` to build the bootloader only.
